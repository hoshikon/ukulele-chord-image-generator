Ukulele Chord Diagram Generator

Type chord names (one per line) — a 777-chord library is built in (from the open-source chords-db, each with a verified fingering). Or give your own frets to override any shape. Everything runs in this one file; nothing is loaded from a server.

One per line. Built-in: just the name — C, Em7, F#m. Type to autocomplete — Tab to complete, ↑/↓ to choose.
Or define inline (strings G C E A; 0=open, x=muted):
{define: Em6 frets 0 1 0 2 fingers 0 1 0 2}

Saved in this browser and overrides the built-in of the same name. Same {define:} syntax as UkeGeeks. Export/Import moves your custom chords to another browser.
